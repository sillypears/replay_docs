## Quick start

```bash
# single file — instant
python3 replay_info.py path/to/match.rpl

# folder
python3 replay_info.py /mnt/files/bitreader/Replays-1.7.0.5/

# deep payload metadata (names, queue, names sanitized)
python3 replay_info.py match.rpl --full
```

Characters 0..17 are **alphabetical internal slug order** ([Character IDs](/reference/characters/)). Slot 14 is reserved — likely the December 2026 character.
